Write a single funny line of 200 characters or fewer. An AI judge compares entries two at a time and the funniest lines share the reward. This entry is the Wi-Fi router's side of "have you tried turning it off and on again": rebooted 400 times and still blamed for everything.

## Run it

```sh
python3 main.py
```

The program writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), gated to one line of 1–200 characters.
